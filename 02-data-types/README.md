# JavaScript Data Types

> Understanding how JavaScript represents, stores, and identifies different types of values.

---

## Overview

This module covers JavaScript data types, including primitive values, reference values, and the `typeof` operator.

The examples are implemented using HTML with external JavaScript files and can be executed directly in a browser.

---

### 03 — `typeof`

The `typeof` operator is used to determine the type of a value.

```js
typeof value;
```

Examples include:

```js
typeof "JavaScript";
typeof 100;
typeof true;
typeof undefined;
typeof null;
typeof {};
typeof [];
```
